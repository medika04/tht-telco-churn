# 📊 Telco Customer Churn Analysis & RFM Segmentation

> A comprehensive end-to-end data analytics project exploring telecommunications customer churn, identifying key drivers using Machine Learning, and segmenting customers via RFM (Recency, Frequency, Monetary) analysis to drive targeted retention strategies.

---

## 🚀 Project Overview
Customer retention is crucial for the telecom industry. This project analyzes customer behavior, identifies primary churn drivers, segments customers based on their value and activity, and provides actionable business recommendations to minimize revenue loss.

---

## 🛠️ Tech Stack & Tools
* **Programming Language:** Python (Pandas, Scikit-Learn, Matplotlib, Seaborn)
* **Machine Learning:** Random Forest / Classification Models (Feature Importance & Churn Drivers)
* **Data Visualization & Dashboarding:** Power BI
* **Version Control:** Git & GitHub

---

## 📈 Key Findings & Insights
1. **High-Value & At-Risk Segment:** Although the *At-Risk High Value* segment contains a smaller headcount (404 customers), they carry the highest average monthly charges ($86.14) with a critical churn rate of 35.6%.
2. **Core Loyal Base:** *Champions / VIP* customers represent our core loyal base with minimal churn risk (14.3%), contributing the largest portion of total revenue ($17.6M).
3. **Hibernating Customers:** The largest group by headcount (3,118 customers) falls into the *Hibernating / Lost* category with a severe churn tendency (40.2%), requiring automated win-back campaigns.
